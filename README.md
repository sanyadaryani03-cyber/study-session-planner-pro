# Study Session Planner Pro

An AI-powered study planning application built with AWS PartyRock to help students create personalized and structured study sessions.

## 🚀 Live Demo

[Open Study Session Planner Pro](https://partyrock.aws/u/Sanyadaryani/EfEWISy-e/Study-Session-Planner-Pro)

## 📌 Project Overview

Study Session Planner Pro is designed to help students organize their study time more effectively. The application uses AI to create a structured study plan based on the student's study requirements and available time.

## ✨ Key Features

- Personalized study session planning
- Structured study schedules
- AI-powered recommendations
- Easy-to-use interface
- Helps students organize their learning time

## 🛠️ Technology

- AWS PartyRock
- Generative AI
- Prompt Engineering

## 🎯 Purpose

The goal of this project is to make study planning easier and more personalized by using generative AI to create useful study-session recommendations.

- Building generative AI applications using AWS PartyRock
- Designing effective prompts
- Structuring AI-powered workflows
- Creating user-focused AI applications
- Exploring practical applications of generative AI
